# 黄色历史实验结果

本页对应黄色10条旧示教，不是红色50条新记录的训练结果。

基础模型为官方 pi0_base，使用 NERO 数据做 LoRA 微调。训练集 8 条、2,710 帧；验证集 2 条、719 帧。批大小为 2，动作块 50 步，模型动作空间 32 维，实际 NERO 输出 16 维。

| 设置 | 值 |
|---|---|
| OpenPI 提交 | `215abfb217dbac7d5f1273282331b9b1866c0479` |
| 数据频率 | 15 Hz |
| 关节动作 | 相对当前观测状态的偏移 |
| 夹爪动作 | 绝对宽度 m |
| 推理采样 | 10 步；按验证帧索引固定噪声 |
| 归一化 | 仅使用训练集；关节标准差下限 0.001 rad，夹爪 0.001 m |

## 离线误差

下表来自已运行的全量验证结果，按三位小数列示。误差越低越好。

| 范围 / 指标 | pi0_base | 100 步 | 1,000 步 | 保持状态 |
|---|---:|---:|---:|---:|
| 首步关节 MAE（度） | 2.190 | 1.541 | 0.631 | 0.373 |
| 首步左夹爪 MAE（mm） | 0.114 | 0.074 | 0.014 | 0.075 |
| 首步右夹爪 MAE（mm） | 8.247 | 6.957 | 5.507 | 1.831 |
| 未来关节 MAE（度） | 5.448 | 4.953 | 3.057 | 3.708 |
| 未来左夹爪 MAE（mm） | 0.332 | 0.223 | 0.056 | 0.075 |
| 未来右夹爪 MAE（mm） | 8.415 | 7.186 | 6.080 | 7.041 |

“保持状态”将当前实测状态作为未来预测。未来动作误差排除轨迹末端填充，共比较 33,500 个有效目标向量。向量之间有重叠，独立验证示教仍为 2 条。

1,000 步模型的未来误差低于保持状态参考；首步关节和右夹爪仍有差距。左夹爪在训练数据中接近常数。上述结果不能换算为实机任务成功率。

## 结果文件

服务器 `results/pi0_nero_box_v1/` 按运行保存：

| 文件 | 内容 |
|---|---|
| 训练 `report.json` | 实验名、步数、检查点路径、首末损失记录 |
| `console.log`、`run.log` | 终端输出和程序日志 |
| `training_metrics.csv/json` | 每 10 步打印的 loss、梯度和参数范数 |
| 对照 `comparison.json` | 基础模型、微调模型、保持状态参考的误差 |
| `trained/report.json`、`base/report.json` | 每个模型的输入来源、参数和评估指标 |
| `validation_actions.npz` | 预测、参考动作、状态、有效掩码、帧索引 |

100 步检查点为 `checkpoints/pi0_nero_box_v1/nero_smoke_v1/99`。1,000 步实验使用独立实验名，最终检查点编号为 `999`；实际名称见本次训练报告。
