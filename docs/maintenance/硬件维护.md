# 硬件维护

维护入口位于 `scripts/maintenance/`，在连接硬件的本地电脑运行：

```bash
cd /home/user/W_pro
.venv/bin/python scripts/maintenance/nero_enable.py --help
.venv/bin/python scripts/maintenance/nero_disable.py --help
.venv/bin/python scripts/maintenance/nero_clear_estop_left.py --help
.venv/bin/python scripts/maintenance/nero_clear_estop_right.py --help
```

| 入口 | 用途 |
|---|---|
| `nero_enable.py` | 使能；`--arm left/right/both` 选择接口 |
| `nero_disable.py` | 失能 |
| `nero_clear_estop_left.py` | 左侧软件急停诊断与恢复 |
| `nero_clear_estop_right.py` | 右侧软件急停诊断与恢复 |

默认预览/诊断，加入 `--execute` 才请求操作。需要先短暂使能才能复位时，使用 `--enable-for-reset`。失能和复位可能撤去力矩，应按现场流程支撑机械臂。

## 适用设备

这些入口保留旧独立机械臂 USB-CAN 映射和 NERO 1.20 配置：

| 侧别 | USB-CAN 序列号 |
|---|---|
| 左 | 002B001D4648570C20303731 |
| 右 | 0020002C4648570A20303731 |

当前示教接线为主从共线，使用另外两只 USB-CAN。维护入口不能在同一总线上唯一选择某台主臂或从臂；实际执行前应核对接线、身份和固件。

`scripts/_common/nero_control_common.py` 和 `nero_local_read.py` 为上述入口的公共模块，不单独执行。现场采集映射见[采集操作](../acquisition/采集操作.md)。
