# 目录维护

本地数据分别放 `data/nero_demos/yellow/` 和 `red/`；派生数据使用 `nero_aligned_批次版本/`、`nero_lerobot_批次版本/`。黄色历史 `nero_aligned_v1` 保留原名，避免与已有报告混淆。

采集代码放 `scripts/acquisition/`，数据转换放 `scripts/data/`，模型工具放 `scripts/model/`，硬件维护放 `scripts/maintenance/`。说明按主题放在 `docs/`，完整操作顺序只以根目录README为准，文件用途集中在[文件索引](文件索引.md)。

## 保留与清理

保留全部60条原始记录、黄色旧对齐、红色新对齐及完整备份分卷。失败记录是独立的采集来源，不当作缓存删除。`data/archive/` 保存本次提交时两批原始记录和对齐数据的无损快照；新增数据需要更新备份。

可清理Python缓存、重复导航文档、被当前工具包替代的旧压缩包。虚拟环境 `.venv` 和厂商SDK是现有采集依赖，不随数据批次清理。

`packages/nero-training-tools.tar.gz` 是当前服务器安装包，替代旧 `vla-wu-layout.tar.gz`。包的内容和重建命令见[packages说明](../../packages/README.md)。数据、模型、环境不放入工具包。

## 服务器旧目录整理（可选）

安装或更新工具包后，单独生成服务器逐文件说明：

```bash
cd /home/clwu/vla-wu && \
python3 scripts/tools/organize_vla_wu.py --project /home/clwu/vla-wu --write-index
```

输出为 `docs/文件索引.md`，包含用途、使用场景、命令和输出位置。此选项不移动或清理文件。

工具包包含 `scripts/tools/organize_vla_wu.py` 及模板。如果服务器还存在根目录旧模型脚本，可先列出操作：

```bash
cd /home/clwu/vla-wu
python3 scripts/tools/organize_vla_wu.py --project /home/clwu/vla-wu
```

确认计划后执行：

```bash
cd /home/clwu/vla-wu && \
python3 scripts/tools/organize_vla_wu.py --project /home/clwu/vla-wu --apply
```

如果根目录与 `scripts/model/` 同时存在同名文件，整理工具会停止，需先人工核对，不能直接合并或覆盖。新批次日常训练不需要反复运行整理工具。

该工具仅处理已识别的旧脚本、缓存、无有效检查点的失败结果，以及被完整结果替代的旧抽样记录。有效模型、正式训练日志及原始数据保留；维护记录位于 `logs/maintenance/layout_*/`。
