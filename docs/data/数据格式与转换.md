## 原始示教文件

| 文件 | 内容 |
|---|---|
| `metadata.json` | 任务、设备、时钟和反馈来源 |
| `can_left.jsonl`、`can_right.jsonl` | 原始 CAN 帧、载荷和主机接收时间 |
| `camera_base.jsonl` 等 | 图像路径、帧号、设备时间及主机接收时间 |
| `images/base/`、`images/left_wrist/`、`images/right_wrist/` | 三路 RGB JPEG |
| `camera_*_device.json` | 型号、序列号和 USB 类型 |
| `samples.jsonl` | 最新状态拼接的参考快照；不作为严格同步帧 |
| `summary.json` | 结束标签、计数、间隔和接收异常 |

## 16 维状态和动作

顺序为：左 J1～J7、左夹爪、右 J1～J7、右夹爪。夹爪通道为从 0 计数的第 7、15 列。

| 字段 | 来源与含义 | 训练单位 |
|---|---|---|
| `state` | 从臂实测关节角和夹爪开口宽度 | rad / m |
| `action` | 总线上的绝对关节目标和夹爪目标宽度 | rad / m |

关节原始计数为 0.001°，夹爪宽度原始计数为 1 μm。原始解码显示 deg/mm，对齐后换算为 rad/m。当前数据没有末端 XYZ、TCP 或深度图。

关节目标来自 `0x155/156/157/170`，关节反馈来自 `0x2A5/2A6/2A7/2A9`；夹爪目标、反馈分别为 `0x159`、`0x2A8`。转换只接受夹爪宽度模式。

## 时间对齐

统一到 15 Hz 主机接收时间轴，取各时刻之前最近收到的图像、状态和目标；不插值，不以参考快照行号配对。图像最大年龄 100 ms，CAN 为 50 ms，CAN 子包接收跨度上限 30 ms。

这是接收时间对齐，相机曝光和控制延迟尚未标定。对齐只裁掉公共区间外的头尾；中间异常会报错。

## 本地处理命令

```bash
cd /home/user/W_pro
.venv/bin/python scripts/data/check_nero_alignment.py
.venv/bin/python scripts/data/export_nero_lerobot.py --dry-run
```

首次生成中间数据：

```bash
.venv/bin/python scripts/data/prepare_nero_dataset.py
```

输出已存在时需指定新的 `--output` 目录。

| 中间文件 | 内容 |
|---|---|
| `dataset_manifest.json` | 字段、采样约定和总量 |
| `split.json` | 整条示教的训练/验证划分 |
| 各示教 `aligned.npz` | 状态、目标、时间轴、图像路径 |
| 各示教 `alignment_report.json` | 来源、接收年龄和裁剪记录 |

中间数据的图像路径引用原始示教。迁移时原始数据和对齐数据一起传输。

## LeRobot 导出

导出脚本使用 LeRobot 0.1.0 的服务器环境。已有数据位于 `~/vla-wu/data/nero_lerobot_v1/`；需要重建时使用新的输出目录。

```bash
cd /home/clwu/vla-wu/vendor/openpi
.venv/bin/python /home/clwu/vla-wu/data/nero_input_v1/scripts/export_nero_lerobot.py \
  --output /home/clwu/vla-wu/data/nero_lerobot_v2
```

LeRobot 字段为 `observation.state`、`action` 和三路 `observation.images.*`，任务文本为 `task`。图像使用 image 特征存储。导出后保留 `export_report.json`、`nero_episode_map.json`，用于对应原始示教。

模型训练时再将 14 个关节目标转换为相对当前观测的偏移，两个夹爪保留绝对宽度。归一化统计仅使用训练集，说明见[vla-wu 使用说明](../model/vla-wu使用说明.md)。
