完整操作顺序与传输命令见[项目总说明](../../README.md)。黄色和红色分别建数据集；当前没有将两批数据合并训练。

红色失败记录 `episode_20261117_155400_379098` 保留在原始目录，对齐清单的 `excluded_episodes` 记录排除原因。记录器的 `errors` 是采集故障，不是“任务中发生过纠正动作”；最终标记成功、采集正常的恢复示教可以进入后续筛选。

每条 `metadata.json` 保存自己的任务：黄色为“用右臂将黄色长方体物体放入透明盒子，然后双臂协作合上盒盖。”；红色为“用右臂将红色物体放入透明盒子，然后双臂协作合上盒盖。”。导出沿用这些文本，不批量改写原始元数据。

## 原始文件

| 文件 | 含义 |
|---|---|
| `metadata.json` | 任务文本、设备、采集设置、时钟锚点、反馈来源声明 |
| `summary.json` | 成功/失败/中止标签、起止时刻、接收统计及采集错误 |
| `can_left.jsonl`、`can_right.jsonl` | 原始CAN帧、载荷和主机接收时刻 |
| `camera_base.jsonl`、`camera_left_wrist.jsonl`、`camera_right_wrist.jsonl` | 图像路径、帧号、设备时间与主机接收时刻 |
| `camera_*_device.json` | 相机型号、序列号和USB类型 |
| `images/base/`、`images/left_wrist/`、`images/right_wrist/` | RGB JPEG，640×480 |
| `samples.jsonl` | 最新状态拼接的参考快照，不能当作严格同步训练帧 |

新采集仅保留成功结束且记录器未报错的记录，失败、中止和诊断试录的临时数据会自动清理。已保存的历史原始文件仍是采集来源，不将既有失败记录、参考快照或旧批次当作缓存删除。每张JPEG按相机角色和索引管理，不逐张写重复说明。

## 状态和动作

顺序为左J1～J7、左夹爪、右J1～J7、右夹爪；夹爪通道从0计数为7、15。

| 字段 | 含义 | 单位 |
|---|---|---|
| `state` | 从臂实测关节角与夹爪总开口 | rad/m |
| `action` | 总线上的绝对关节目标与夹爪目标宽度 | rad/m |

关节原始计数为0.001°，夹爪宽度为1 μm。目标ID为 `0x155/156/157/170` 和 `0x159`；反馈为 `0x2A5/2A6/2A7/2A9` 和 `0x2A8`。只接受夹爪宽度模式，不将角度模式数值按米解释。

## 时间和划分

按主机接收时间统一到15 Hz，选择各时刻之前最近的图像、状态和目标，不插值、不移动动作时间。图像最大年龄100 ms，CAN最大年龄50 ms，单侧CAN子包跨度最多30 ms。只裁掉共同有效区间之外的头尾，内部异常会停止构建。

这是接收时间对齐，相机曝光及控制延迟未标定。按整条示教、随机种子42划分；默认约20%留出，也可用 `--validation-count` 明确指定。不得把同一示教的相邻帧拆进训练和验证两边。

## 对齐输出

| 文件 | 含义 |
|---|---|
| `dataset_manifest.json` | 批次、字段、相机顺序、总量、每条来源和排除记录 |
| `split.json` | 训练/验证episode名称及随机种子 |
| 各episode的 `aligned.npz` | 16维状态/目标、时间轴、图像路径、所选原始报文时刻 |
| 各episode的 `alignment_report.json` | 原始目录、任务、裁剪范围和来源信息 |

黄色旧对齐文件的路径没有随原始目录移动而修改，检查时用 `--raw-root data/nero_demos/yellow`。导出器同样按每条旧来源目录下的相对图像路径映射到新位置，不回退读取旧机器路径。

## LeRobot与模型

本地预检查不需要LeRobot；正式导出使用服务器已有LeRobot 0.1.0。字段为 `observation.state`、`action`、三路 `observation.images.*`、`task`；图像存为image特征，不用视频或深度图。

红色输出使用 `data/nero_lerobot_red_v1/`，repo分别为 `local/nero_red_v1_train`、`local/nero_red_v1_validation`。先导出，再使用 `nero_batch.py prepare --dataset red_v1` 生成训练集统计。模型数据变换将14个关节目标转换为相对当前观测的偏移，两夹爪保留绝对宽度，模型端补到32维、预测50步。

新批次不可复用黄色统计；生成新版本时同时更新对齐目录、LeRobot目录、repo-prefix和模型 `--dataset`。具体命令统一见总说明，避免多份流程相互过时。
