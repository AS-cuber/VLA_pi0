# 采集操作

采集与后续训练的完整顺序见[项目总说明](../../README.md)。本页命令在连接相机与 USB-CAN 的本地电脑运行：

```bash
cd /home/user/W_pro
```

## 设备映射

| 设备 | 接口 / 序列号 |
|---|---|
| 左主臂、左从臂总线 | can1；004B003A4648571020363032 |
| 右主臂、右从臂总线 | can0；004800254148571320343133 |
| 基座 D435 | 263022078897 |
| 左腕 D435 | 263022072396 |
| 右腕 D435 | 263022078453 |

当前采集参数为三路 RGB、640×480、15 fps。相机使用 USB 2.1 连接；深度图未纳入训练数据。

## 启动 CAN

查看接口：

```bash
ip -details -statistics link show type can
```

接口为 DOWN 时按 1 Mbps 启用：

```bash
sudo ip link set can0 up type can bitrate 1000000
sudo ip link set can1 up type can bitrate 1000000
```

已 UP 且比特率正确时直接使用。`ERROR-ACTIVE` 是 CAN 正常工作状态；`BUS-OFF` 需要检查接线、速率和设备状态。

核对两侧反馈：

```bash
cd /home/user/W_pro && \
.venv/bin/python scripts/acquisition/nero_teleop_read.py --seconds 10
```

接口编号重插后可能改变，程序会校验 USB 序列号。正式录制使用从臂反馈；本批示教采用主臂关闭反馈推送、从臂开启反馈推送的配置，并与从臂上位机核对过来源。CAN ID 本身不能区分同总线上的物理机械臂。

## 查看相机

```bash
cd /home/user/W_pro && \
.venv/bin/python scripts/acquisition/test_three_cameras.py
```

在 Viewer 中开启 RGB Camera，切到 2D 检查三路画面。测试深度时开启 Stereo Module。检查结束关闭 Viewer，再启动采集，避免相机被占用。

## 录制示教

需要观察设备接收情况时，可做10秒临时试录；计数在终端显示，结束后不保留数据：

```bash
cd /home/user/W_pro && \
.venv/bin/python scripts/acquisition/record_nero_demo.py \
  --output /tmp/nero_diagnostics --headless --seconds 10 --camera-fps 15
```

录制完整任务：

```bash
cd /home/user/W_pro && \
.venv/bin/python scripts/acquisition/record_nero_demo.py \
  --output data/nero_demos/red --camera-fps 15 \
  --prompt '用右臂将红色物体放入透明盒子，然后双臂协作合上盒盖。' \
  --feedback-source-confirmed \
  --feedback-source-note '两主臂反馈推送关闭，两从臂开启；已对照从臂上位机核实关节反馈'
```

确认来源的两个参数记录现场核对结果。每条示教先恢复物体、盒盖、相机和机械臂初始布置，等待窗口显示 `READY`。

| 按键 | 操作 |
|---|---|
| S | 开始记录 |
| F | 成功保存 |
| X | 失败丢弃 |
| Esc / 关闭窗口 | 中止并丢弃 |

按键需采集窗口获得焦点。录制期间数据写入输出目录下的隐藏 `.recording_*` 临时目录；按F且记录器未报错时，等待写入结束后转为正式的 `data/nero_demos/red/episode_日期_时间/`。失败、中止、Ctrl+C、计时结束或采集异常都会丢弃本轮数据，不留下正式示教目录。窗口尺寸默认跟随启动终端，可用 `--no-follow-terminal` 关闭；保存分辨率不随窗口变化。

采集器只接收数据。退出窗口、Ctrl+C 和录制结束均不会停止机械臂或主从联动。

## 检查示教

将实际目录代入：

```bash
cd /home/user/W_pro && \
.venv/bin/python scripts/data/check_nero_demo.py \
  data/nero_demos/red/episode_20261117_154334_742573
```

文件说明和后续对齐见[数据格式与转换](../data/数据格式与转换.md)。

当前 `yellow/` 保存原10条黄色示教，`red/` 保存新50条红色记录。采集黄色任务时必须同时更改输出目录与任务文本。诊断试录临时写入 `/tmp/nero_diagnostics` 下，结束后自动清理。此保存规则用于今后的采集，既有示教文件不改变。
