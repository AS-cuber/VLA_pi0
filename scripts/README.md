# 脚本入口

| 分组 | 运行电脑 | 说明 |
|---|---|---|
| `acquisition/` | 连接设备的本地电脑 | [采集操作](../docs/acquisition/采集操作.md) |
| `data/` | 本地检查；LeRobot 正式导出在服务器 | [数据格式与转换](../docs/data/数据格式与转换.md) |
| `model/` | GPU 服务器；部分分析只需 CPU | [vla-wu 使用说明](../docs/model/vla-wu使用说明.md) |
| `maintenance/` | 本地硬件电脑 | [硬件维护](../docs/maintenance/硬件维护.md) |
| `_common/` | 公共模块 | 由硬件维护入口导入 |
| `tools/` | 本地打包、服务器整理 | [目录维护](../docs/maintenance/目录维护.md) |

每个文件的用途、输入输出和命令见[文件索引](../docs/maintenance/文件索引.md)。
