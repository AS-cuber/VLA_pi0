# 服务器目录

| 路径 | 内容 |
|---|---|
| `vendor/openpi/`、`.venv/` | 官方OpenPI源码及其已有Python环境，环境位于OpenPI内部 |
| `checkpoints/openpi-assets/checkpoints/pi0_base/` | 官方基础权重 |
| `data/nero_demos/red/` | 新50条红色原始记录 |
| `data/nero_aligned_red_v1/` | 本地已对齐的49条成功红色示教 |
| `data/nero_lerobot_red_v1/` | 红色LeRobot导出及报告 |
| `data/nero_openpi_cache_red_v1/` | 本批次训练repo的目录链接 |
| `assets/pi0_nero_red_v1/` | 本批次训练集归一化统计 |
| `checkpoints/pi0_nero_red_v1/` | 本批次各独立实验的检查点 |
| `results/pi0_nero_red_v1/` | 训练日志、指标、验证预测 |
| `data/nero_lerobot_v1/`、`data/nero_openpi_cache_v1/` | 黄色旧批次数据和链接 |
| `assets/pi0_nero_box_v1/`、`checkpoints/pi0_nero_box_v1/`、`results/pi0_nero_box_v1/` | 黄色旧统计、模型与结果 |
| `data/nero_input_v1/` | 黄色旧迁移来源；若存在则保留 |
| `scripts/model/`、`scripts/data/` | 模型与导出工具 |
| `scripts/tools/` | 目录维护工具和模板 |
| `docs/` | 服务器运行与历史说明 |

新数据使用新的批次版本，同时更新LeRobot目录、repo、统计和实验名。不把旧统计复制到新批次，不批量删除原始记录或有效模型。
