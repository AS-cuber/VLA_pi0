# 目录与数据文件

| 目录 / 文件 | 用途 |
|---|---|
| `scripts/model/` | NERO 项目代码；文件索引中列出每个入口 |
| `scripts/tools/` | 项目整理工具及文档模板 |
| `vendor/openpi/` | OpenPI 源码，内部结构见其 README |
| `vendor/openpi/.venv/` | 服务器模型运行环境 |
| `checkpoints/openpi-assets/checkpoints/pi0_base/params/` | 官方基础模型参数 |
| `checkpoints/pi0_nero_box_v1/实验名/编号/params/` | 微调后的模型参数 |
| 同检查点 `train_state/` | 训练状态与优化器信息 |
| 同检查点 `assets/local/nero_box_v1_train/norm_stats.json` | 随检查点保存的训练集统计 |
| `assets/pi0_nero_box_v1/local/nero_box_v1_train/norm_stats.json` | 项目训练集统计 |
| 同目录 `nero_norm_report.json` | 统计来源、变换、样本数和尺度下限 |
| `data/nero_input_v1/` | 从采集电脑迁移的原始示教、对齐数据和导出来源 |
| `data/nero_lerobot_v1/train/` | 8 条训练示教、2,710 帧 |
| `data/nero_lerobot_v1/validation/` | 2 条验证示教、719 帧 |
| `data/nero_lerobot_v1/export_report.json` | 导出状态、字段语义和来源 |
| 各集合 `nero_episode_map.json` | LeRobot episode 与原始示教的对应关系 |
| `data/nero_openpi_cache_v1/` | 指向训练集的链接，供 OpenPI 按 repo_id 读取 |
| `.cache/` | 下载缓存；可能包含模型依赖文件 |
| `results/pi0_nero_box_v1/train_*/` | 每次训练的日志、指标和报告 |
| `results/pi0_nero_box_v1/comparison_*/` | 完整离线模型对照 |
| `logs/maintenance/layout_*/` | 目录移动清单及被更新文档的原件 |
| `setup_openpi.sh` | 环境安装入口（如存在），从项目根目录运行 |

## 评估文件

| 文件 | 内容 |
|---|---|
| `comparison.json` | 基础模型、微调模型、保持状态参考的误差对照 |
| `trained/report.json`、`base/report.json` | 各模型的完整评估记录和逐帧来源 |
| `validation_actions.npz` | predictions、references、states、valid_mask、dataset_indices |
| `action_diagnostics_*/diagnostics.json` | 可选的分预测距离、分关节及夹爪偏差分析 |
| `horizon_errors.csv` | 不同预测距离的误差与保持状态参考 |
| `right_gripper_first_actions.csv` | 右夹爪逐帧目标、预测和实测状态 |

实际存在的脚本见[文件索引](文件索引.md)，运行命令见[运行说明](运行说明.md)。

目录整理保持数据、统计、权重、运行环境和正式结果原路径。清理范围为 Python 缓存、没有有效检查点或有效子结果的失败运行、已被完整对照替代的抽样试跑及核对一致的输入压缩包。未确认用途的额外文件会保留并列出。
