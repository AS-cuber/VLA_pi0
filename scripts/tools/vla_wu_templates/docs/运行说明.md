# 运行说明

所有命令从项目根目录运行：

```bash
cd {{PROJECT}}
nvidia-smi
```

Python 使用 `vendor/openpi/.venv/bin/python`。下列 GPU 命令选择物理 GPU 1，按实际空闲显卡调整。进程中取消系统 CUDA 库路径，沿用当前 JAX 环境。

## 模型文件

| 文件 | 用途 |
|---|---|
| `nero_pi0_adapter.py` | 三路 RGB、16 维 rad/m 状态/动作适配；由其他文件导入 |
| `nero_pi0_config.py` | NERO 数据变换及 LoRA 默认配置；由运行入口读取 |
| `prepare_nero_pi0.py` | 读取 train，建立查找链接并生成归一化统计 |
| `run_nero_pi0.py` | verify 验证基础模型加载；train 创建独立微调实验 |
| `check_nero_checkpoint.py` | 检查点重载、验证集预测和基础模型对照 |
| `diagnose_nero_actions.py` | 可选：读取预测 NPZ，分解预测距离和夹爪误差 |

脚本路径统一为 `scripts/model/文件名`，每个入口的参数可通过 `--help` 查看。可选诊断文件可能尚未上传，见实际文件索引。

## 训练

```bash
env -u LD_LIBRARY_PATH -u LD_PRELOAD \
  CUDA_VISIBLE_DEVICES=1 JAX_PLATFORMS=cuda \
  XLA_PYTHON_CLIENT_PREALLOCATE=false \
  vendor/openpi/.venv/bin/python -u scripts/model/run_nero_pi0.py train \
  --steps 1000 --save-interval 250 \
  --exp-name "nero_1000_$(date +%Y%m%d_%H%M%S)"
```

从 `checkpoints/openpi-assets/checkpoints/pi0_base/params` 初始化。batch=2，NERO 16 维数据补齐至模型的 32 维。14 个关节目标转换为相对当前观测的偏移，夹爪保留绝对宽度。

训练写入 `checkpoints/pi0_nero_box_v1/实验名/`。100 步最终编号 99，1,000 步最终编号 999。已有实验名会停止；新实验使用独立名称。当前 1,000 步设置只保留该实验最新检查点。

终端显示本次结果目录，其中：

- `report.json`：完成状态、实验名、实际参数和检查点目录。
- `run.log`：程序日志。
- `console.log`：包括进度条在内的终端输出。
- `training_metrics.csv/json`：每 10 步打印的指标；列名为 step、grad_norm、loss、param_norm。

最后打印 step 990 属于 1,000 步运行的正常记录间隔。完成状态以 report.json 和最终检查点为准。

## 全量评估

把命令中的 `实验名` 替换为实际名称：

```bash
env -u LD_LIBRARY_PATH -u LD_PRELOAD \
  CUDA_VISIBLE_DEVICES=1 JAX_PLATFORMS=cuda \
  XLA_PYTHON_CLIENT_PREALLOCATE=false \
  vendor/openpi/.venv/bin/python -u scripts/model/check_nero_checkpoint.py \
  --checkpoint {{PROJECT}}/checkpoints/pi0_nero_box_v1/实验名/999 \
  --all-frames --compare-base
```

先运行训练模型，再运行原始 pi0_base，两者使用相同 NERO 输入、训练集统计及采样噪声。输出目录为 `results/pi0_nero_box_v1/comparison_随机后缀/`。

`--all-frames` 覆盖两条验证示教共 719 帧；不加时抽样 6 个时刻。`--compare-base` 自动汇总对照；不加时只评估所选检查点。

## 归一化和加载验证

已有统计在 `assets/pi0_nero_box_v1/local/nero_box_v1_train/`。首次生成统计：

```bash
env -u LD_LIBRARY_PATH -u LD_PRELOAD JAX_PLATFORMS=cpu \
  vendor/openpi/.venv/bin/python -u scripts/model/prepare_nero_pi0.py
```

仅使用 8 条训练示教；输出已存在时停止。源数据、模型变换及统计应配套使用。

基础模型加载验证：

```bash
env -u LD_LIBRARY_PATH -u LD_PRELOAD \
  CUDA_VISIBLE_DEVICES=1 JAX_PLATFORMS=cuda \
  XLA_PYTHON_CLIENT_PREALLOCATE=false \
  vendor/openpi/.venv/bin/python -u scripts/model/run_nero_pi0.py verify
```

可选的 CPU 动作分析：

```bash
vendor/openpi/.venv/bin/python scripts/model/diagnose_nero_actions.py
```

输入为现有 `validation_actions.npz`，输出为分预测距离的误差表和右夹爪逐帧 CSV。该工具是辅助分析，不是开始实机评估的前置步骤。
