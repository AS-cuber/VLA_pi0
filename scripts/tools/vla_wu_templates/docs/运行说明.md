# 服务器运行说明

以下命令在GPU服务器项目根目录执行，默认 `/home/clwu/vla-wu`。本地先同步 `data/nero_demos/red/` 和 `data/nero_aligned_red_v1/`，后者包含49条成功示教的39/10划分。原始失败记录保留，不进入本批次训练。

## 红色批次

LeRobot导出，输出目录必须尚未存在：

```bash
cd /home/clwu/vla-wu
vendor/openpi/.venv/bin/python scripts/data/export_nero_lerobot.py \
  --aligned data/nero_aligned_red_v1 --raw-root data/nero_demos/red \
  --output data/nero_lerobot_red_v1 --repo-prefix local/nero_red_v1
```

仅用训练集数值计算统计：

```bash
cd /home/clwu/vla-wu && \
env -u LD_LIBRARY_PATH -u LD_PRELOAD JAX_PLATFORMS=cpu \
  vendor/openpi/.venv/bin/python -u scripts/model/nero_batch.py prepare \
  --project /home/clwu/vla-wu --dataset red_v1
```

选择空闲GPU，示例使用GPU 1，首轮1,000步：

```bash
cd /home/clwu/vla-wu && \
nvidia-smi
NERO_EXP="red_1000_$(date +%Y%m%d_%H%M%S)"
env -u LD_LIBRARY_PATH -u LD_PRELOAD \
  CUDA_VISIBLE_DEVICES=1 JAX_PLATFORMS=cuda XLA_PYTHON_CLIENT_PREALLOCATE=false \
  vendor/openpi/.venv/bin/python -u scripts/model/nero_batch.py train \
  --project /home/clwu/vla-wu --dataset red_v1 \
  --exp-name "$NERO_EXP" --steps 1000 --save-interval 250
```

训练从官方pi0_base开始，已有黄色微调模型不参与初始化。1,000步是首轮配置，不代表已收敛。保留所选实验名，最终检查点编号为999。

按需评估，沿用同一终端中的实验名：

```bash
cd /home/clwu/vla-wu && \
NERO_CHECKPOINT="/home/clwu/vla-wu/checkpoints/pi0_nero_red_v1/$NERO_EXP/999"
env -u LD_LIBRARY_PATH -u LD_PRELOAD \
  CUDA_VISIBLE_DEVICES=1 JAX_PLATFORMS=cuda XLA_PYTHON_CLIENT_PREALLOCATE=false \
  vendor/openpi/.venv/bin/python -u scripts/model/nero_batch.py evaluate \
  --project /home/clwu/vla-wu --dataset red_v1 \
  --checkpoint "$NERO_CHECKPOINT" --all-frames
```

更换终端时填写实际检查点路径。省略 `--all-frames` 时每条验证示教抽开始、中间、末尾三个时刻。全量使用本批次3,158帧，不按旧719帧处理。

## 文件用途

| 文件 | 用途与调用方式 |
|---|---|
| `scripts/data/export_nero_lerobot.py` | 对齐数据导出train/validation；上文给出完整命令 |
| `scripts/model/nero_batch.py` | 新命名批次的prepare/train/evaluate入口；参数用 `--help` 查看 |
| `scripts/model/nero_pi0_adapter.py` | 三相机与16维rad/m变换；公共模块 |
| `scripts/model/nero_pi0_config.py` | LoRA、50步动作块、模型32维等基础配置；公共模块 |
| `scripts/model/prepare_nero_pi0.py` | 黄色旧8/2批次的统计入口；新批次仅复用其中统计函数 |
| `scripts/model/run_nero_pi0.py` | 黄色旧批次的verify/train；也是日志等公共函数来源 |
| `scripts/model/check_nero_checkpoint.py` | 黄色旧批次检查点评估与基础模型对照；新入口复用误差计算函数 |
| `scripts/model/diagnose_nero_actions.py` | 黄色旧719帧结果的可选CPU分析 |
| `scripts/tools/organize_vla_wu.py` | 旧根目录脚本归类、清理已识别临时产物；默认仅列计划 |
| `scripts/tools/vla_wu_templates/` | 此服务器README和说明的模板来源 |
| 各级 `__init__.py` | Python包与相邻模块导入入口，不单独运行 |

黄色旧命令和模型路径保留，详见 `docs/model/vla-wu使用说明.md`（训练工具包提供）及[历史实验结果](实验结果.md)。
